## Остаточные замечания

- Интеграции Resend, Google, Telegram и OpenAI требуют реальные ключи в `apps/api/.env`.
- `node_modules`, `dist`, `.log` и `*.tsbuildinfo` не нужны для передачи дипломных Word-документов.
- Для защиты важно заранее подготовить демонстрационные аккаунты покупателя, продавца и администратора.
- Для сдачи Word-документов открывать комплект из `DayenDiplom/Готово`; корневой `DayenDiplom/Отзыв+.docx` является отдельной копией.
- Markdown-файлы `docs/diploma-dayen/*.md` являются черновыми исходниками: в них остаются плейсхолдеры титульных данных, страниц содержания и мест для скриншотов. Для защиты использовать готовые `.docx` из `DayenDiplom/Готово`.
- Для демонстрации проекта не использовать HTML-файлы из `legacy/`; актуальный frontend находится в `apps/web`.
- После финального разрешения можно удалить неиспользуемые barrel-файлы `features/*/pages/index.ts`; сейчас они не мешают сборке.

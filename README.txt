# Dayen Marketplace

Dayen Marketplace - дипломный проект web-приложения маркетплейса.
В проект входят frontend на React/TypeScript, backend API на Node.js/Express,
база данных PostgreSQL, роли покупателя, продавца, администратора и владельца.

## Что открыть в колледже

Главный файл для передачи и открытия:

```txt
DayenDiplom.zip
```

Внутри архива находится папка:

```txt
DayenDiplom/Готово
```

Открывать нужно Word-файлы из этой папки:

```txt
+1 Титульный лист+.docx
2 Задание+.docx
3 Содержание.docx
4 Введение+.docx
5 Общая часть .docx
6 Специальная часть .docx
7 Организация производства .docx
8 Экономическая часть.docx
9 Охрана труда+.docx
10 Заключение+.docx
11 Приложения+.docx
12 Приложение А+листинг.docx
13 Приложение Б вход.docx
14 Приложение В выход.docx
15 Приложение Г схема.docx
16 Приложение Д .docx
17 Приложение Е .docx
18 Список литературы+.docx
Отзыв+.docx
```

Если в архиве также виден `DayenDiplom/Отзыв+.docx` вне папки `Готово`, для сдачи используйте версию из `DayenDiplom/Готово`.
Если Word откроет документ в защищенном режиме, нажмите "Разрешить редактирование".
Если колледжский компьютер не умеет открывать архив напрямую, сначала распакуйте `DayenDiplom.zip`, потом открывайте `.docx`.

## Где что лежит

```txt
DayenDiplom.zip          - готовый архив дипломных Word-файлов
DayenDiplom/             - распакованная копия готового дипломного комплекта
docs/diploma-dayen/      - рабочие исходные тексты диплома
apps/web/                - frontend React/Vite/TypeScript
apps/api/                - backend Express/TypeScript/PostgreSQL
storage/uploads/         - локальные загруженные изображения
legacy/                  - старая справочная версия, не основной frontend
```

Для сдачи документации в колледже обычно нужен только `DayenDiplom.zip`.
Для демонстрации работающего проекта нужны `apps/web`, `apps/api`, `package.json` и база данных.
Папка `legacy/` оставлена только как архив старой статической версии. Для защиты открывайте React-приложение из `apps/web`, а не HTML-файлы из `legacy/`.

## Возможности проекта

- Каталог товаров, поиск, плитки разделов и карточка товара.
- Регистрация, вход, подтверждение email, сброс пароля.
- Корзина, оформление заказа, страница оплаты и история заказов.
- Избранное, уведомления, профиль и настройки аккаунта.
- Кабинет продавца: профиль магазина, товары, продажи, обращения.
- Админ-панель: пользователи, товары, разделы, плитки, заказы, баннеры, заявки продавцов и поддержка.
- Загрузка изображений, роли доступа, 2FA для важных действий и журнал аудита.

## Локальный запуск проекта

Установить зависимости:

```bash
npm install
npm --prefix apps/api install
npm --prefix apps/web install
```

Создать файл `apps/api/.env` на основе `apps/api/.env.example`.
Минимальный пример:

```env
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/di2
APP_BASE_URL=http://localhost:5173
UPLOAD_DIR=../../storage/uploads
PORT=3000
RUN_MIGRATIONS_ON_START=1
```

Запустить backend и frontend:

```bash
npm run api:dev
npm run web:dev
```

Адреса по умолчанию:

```txt
API: http://localhost:3000
Web: http://localhost:5173
```

## Важно

- Не храните реальные пароли, токены и API-ключи в README или example-файлах.
- `node_modules`, `dist`, `.log` и `*.tsbuildinfo` - служебные файлы, для сдачи дипломных Word-документов они не нужны.
- Если нужно передать только дипломные документы, передавайте `DayenDiplom.zip`.
- Если нужно демонстрировать проект, запускайте текущую версию через `npm run api:dev` и `npm run web:dev`.
